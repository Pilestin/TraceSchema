# Trace Schema 

Bu repo bir python kodunun execution trace anında çıktılarının standart bir xml formatında tutulması için oluşturulan XSD şemasını tanıtır. En son versiyonu, dökümanlarını ve önceki versiyonlar ile farklarını içerir. Örnek xml'ler ile anlaamayı kolaylkaşyırmayı hedefler.

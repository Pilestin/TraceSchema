Schema v2.2 Documentation

v2.2, v2.1'in üzerine inşa edilmiş bir güncellemedir. ScopeType ve IterationType'a UNIX timestamp tabanlı zamanlama attribute'ları eklendi. ExceptionType'a tam stack trace için <traceback> elementi, MetadataType'a ise <targets> ve <source_files> elementleri eklendi. Tüm yeni alanlar opsiyoneldir — v2.1 dosyaları geçerliliğini korur.v2.2 builds on v2.1. UNIX-timestamp-based timing attributes were added to ScopeType and IterationType. A <traceback> element for full stack trace capture was added to ExceptionType, and <targets> and <source_files> elements were added to MetadataType. All new fields are optional — v2.1 files remain valid.

Download XSD v2.1 → v2.2 Diff v2.1 Docs

✨ What's new in v2.2

  • Added: start_time, end_time, duration attributes on ScopeType — function-level UNIX timestamp timing
  • Added: start_time, end_time attributes on IterationType — per-iteration timing
  • Added: Optional <traceback> element inside ExceptionType — full stack trace string (traceback.format_tb() output)
  • Added: Optional <targets> element inside MetadataType — lists instrumented functions/files
  • Added: Optional <source_files> element inside MetadataType — lists traced source files
  • Changed: xs:schema version updated from "2.1" to "2.2"
  • Note: All new fields are optional (minOccurs="0" / use="optional") — v2.1 files remain valid

🔄 Changed in v2.2

ScopeType
CHG v2.2 complexType ▶
Fonksiyon scope'unu hiyerarşik olarak gruplar. v2.2'de üç opsiyonel zamanlama attribute'u eklendi: start_time (call event UNIX timestamp), end_time (return/exception timestamp) ve duration (hesaplanmış süre, saniye). Bu alanlar post-mortem performans analizi için kullanılır.Groups function scope hierarchically. In v2.2, three optional timing attributes were added: start_time (call event UNIX timestamp), end_time (return/exception timestamp), and duration (computed duration in seconds). These fields are used for post-mortem performance analysis.

Inherited from v2.1

IterationType (xs:choice — v2.1 change)
CHG v2.1 complexType ▶
v2.1'de IterationType içindeki content model xs:sequence'den xs:choice'a dönüştürüldü. Böylece iterasyon içinde iç içe scope ve loop elementleri desteklenmeye başlandı. Ayrıca v2.2'de start_time ve end_time attribute'ları eklendi. Detaylar için Changed in v2.2 → IterationType'a bakın.In v2.1, IterationType's content model was changed from xs:sequence to xs:choice. This enabled nested scope and loop elements inside iterations. In v2.2, start_time and end_time attributes were also added. See Changed in v2.2 → IterationType.

In v2.1, an optional variable attribute was added — it has the same meaning as name and is kept for backward compatibility.

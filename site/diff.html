Changelog Summary

NEW

New: <loop>

Loop compaction element. Groups loop iterations with per-iteration events, optional truncated_iterations and <summary> for skipped iterations.

NEW

New: <scope>

Hierarchical function scope grouping. Recursive structure — nested scopes supported. Child events inherit file and function from parent scope, reducing redundancy.

NEW

New: <thread>

Thread-based event grouping container. Groups event | loop | scope children under a named thread with an id attribute.

NEW

New: schema_version attribute on <trace>

Root element now carries a schema_version attribute (required, e.g. "2.0"). Also added as optional element inside MetadataType.

CHG

Changed: EventsType

v1 used a flat <event> sequence. v2 uses xs:choice allowing event | loop | scope | thread as siblings.

CHG

Changed: EventType field cardinality

thread_id, file, function, caller changed from minOccurs="1" to minOccurs="0". When inside a <scope> or <thread>, these are inferred from the parent.

CHG

Changed: <locals> behavior

In v1, <locals> could appear in any event. In v2, <locals> is only written for call and return events. Line events use <delta> only.

v2.3 - Latest

Schema v2.3 Documentation

v2.3, v2.2 üzerine backward dynamic slicing desteği ekler. Satır event'leri artık opsiyonel <reads> bloğu ile okunan değişkenleri taşıyabilir; kök <trace> altında opsiyonel <slice> bloğu ise seçilen kritere göre slice'a dahil edilen event ve sentetik düğümleri listeler.v2.3 extends v2.2 with backward dynamic slicing support. Line events can now carry an optional <reads> block for variables read by the statement; the root <trace> can include an optional <slice> block listing events and synthetic nodes included in the selected slice.

Download XSD v2.2 → v2.3 Diff v2.2 Docs

What's new in v2.3

  • Added: Optional root-level <slice> element with criterion, criterion_event, and include_control attributes.
  • Added: Optional <reads> element inside EventType to record read/use variables for dynamic slicing.
  • Added: ReadsType, SliceType, SliceNodeType, and SliceDependencyEnum.
  • Changed: xs:schema version updated from "2.2" to "2.3".
  • Compatibility: All v2.3 additions are optional, so v2.2 XML remains valid against the v2.3 schema except for expected version metadata checks.

Inherited from v2.2

timing

Scope and iteration timing

ScopeType keeps optional start_time, end_time, and duration; IterationType keeps optional start_time and end_time.

meta

Targets and source files

MetadataType still supports optional <targets> and <source_files> for trace context.

debug

Exception traceback

ExceptionType still supports optional <traceback> for full stack trace capture.

Compact XML Example

<trace schema_version="2.3">
  <metadata>...</metadata>
  <events>
    <scope function="add" file="example.py" call_line="1" depth="1">
      <event id="2" type="line" timestamp="1705312800.002" depth="1">
        <line>2</line>
        <source>result = a + b</source>
        <delta>
          <change name="result" action="added" type="int"><new>8</new></change>
        </delta>
        <reads>
          <read name="a" type="int">3</read>
          <read name="b" type="int">5</read>
        </reads>
      </event>
      <return_value name="result" type="int">8</return_value>
    </scope>
  </events>
  <slice criterion="result" criterion_event="2" include_control="true">
    <node line="2" event_id="2" function="add" file="example.py" dependency="criterion" source="result = a + b"/>
  </slice>
</trace>

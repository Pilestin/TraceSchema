v2.0 — Latest

Schema v2 Documentation

v2, trace verisini hiyerarşik yapıda organize eder: scope (fonksiyon grubu), loop (döngü compaction) ve thread (thread grubu) elementleri eklendi. locals artık sadece call/return eventlerinde; line eventleri yalnızca delta kullanır. v2 organizes trace data hierarchically: scope (function grouping), loop (loop compaction), and thread (thread grouping) elements were added. locals is now only written for call/return events; line events use only delta.

Download XSD Download Report (DOCX) v1 → v2 Diff

✨ What's new in v2.0

  • Added <loop> element for loop compaction with per-iteration grouping
  • Added <scope> element for hierarchical function grouping (recursive)
  • Added <thread> element for thread-based event grouping
  • Added schema_version attribute on root <trace>
  • Changed: <locals> no longer written for every line event (delta-only)
  • Changed: EventsType supports event | loop | scope | thread as children
  • Changed: EventType fields thread_id, file, function, caller are now minOccurs="0"

NEW v2complexType▶
Döngü event'lerini kompakt biçimde gruplar. Her iterasyon ayrı bir <iteration> elementi. max_iterations kullanıldığında atlanan iterasyonlar truncated_iterations ile belirtilir.Groups loop events compactly. Each iteration is a separate <iteration> element. When max_iterations is used, skipped iterations are indicated by truncated_iterations.

Schema v2.1 Documentation

v2.1, v2.0'un küçük ama anlamlı bir güncellemesidir. IterationType artık iterasyon içinde iç içe scope ve loop destekliyor (xs:choice). DeltaChangeType'a geriye dönük uyumluluk için opsiyonel variable attribute eklendi.v2.1 is a minor but meaningful update on v2.0. IterationType now supports nested scope and loop inside iterations (xs:choice). An optional variable attribute was added to DeltaChangeType for backward compatibility.

Download XSD v2 → v2.1 Diff v2 Docs

✨ What's new in v2.1

  • Changed: IterationType now uses xs:choice — supports event | scope | loop inside iterations (nested calls/loops inside loop bodies)
  • Added: Optional variable attribute on DeltaChangeType (alias for name, kept for backwards compatibility)
  • Changed: xs:schema version updated from "2.0" to "2.1"

🔄 Changed in v2.1

IterationType
CHG v2.1complexType▶
Döngünün tek bir iterasyonu. v2.1'de içerik xs:choice ile genişletildi: artık sadece düz <event> listesi değil, iç içe scope ve loop da destekleniyor.A single loop iteration. In v2.1, the content model was extended with xs:choice: nested scope and loop elements are now supported, not just a flat <event> list.

NEW v2complexType▶
